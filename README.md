# C Programs Collection 🧑‍💻

A structured collection of C programs covering fundamental concepts in the C programming language.

## 📌 About
This repository contains programs written while learning and understanding core C concepts. The focus is on clarity, simplicity, and building a strong foundation.

## 🧠 Topics Covered
- Basic Programs (input/output, operators)
- Conditional Statements (if, switch)
- Loops (for, while, do-while)
- Functions
- Arrays
- Strings
- Pointers
- Structures
- File Handling

## ⚙️ How to Run

### Compile
```bash
gcc filename.c -o output
```

### Run
```bash
./output
```

## 🎯 Goal
To build a solid understanding of C programming and improve problem-solving skills.
